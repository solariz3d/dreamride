# THE MOVE BOOK: hand-written, graph-native modules the stream arranges (src/compose/book.rs).
#
# Written by judgment on 2026-11-03, after listening found stream v2's way of changing intelligent but its content
# flat, and a saved stretch was liked for a simple bass under a lead that wanders in an interesting way (a blancmange curve read at three time scales, gliding between eighths). The brain
# writes the material here; the stream's arc planner only chooses and arranges it.
#
# Format. A module starts with `== id | slot | energy E | density D | mood words | glide` (glide only on modules whose
# line bends or glides continuously), then one `#` line saying the shape, then its definitions and its voice blocks in
# the song language. Every definition a module writes is a CONSTANT reading t (or a function of a step index); the voice
# blocks only read them, so the equation panel shows the whole shape. Energy and density run 1 (space) to 3 (full).
#
# The contract that lets any module sit on any progression (since 2026-11-03, "harmony is written, never generated"):
#   - the progression is one of the written ones in `harmony.txt` (src/compose/harmony.rs): it writes `c` (the melody's
#     mode for the lens `h`) and four digit tables, one digit a half bar; the stream writes the key `K` once a song;
#   - every tonal module reads the chord of half bar i = floor(t / 2): `Hr(i)` the bass note, `Hv(m, i)` the pads' voice
#     m as voice-led, `Hc(m, i)` chord tone m up a ladder from the bass, `sc(x, i)` the chord tone nearest x;
#   - melodic lines live in scale degrees through `h` and are pulled to the nearest chord tone on the strong beats
#     (beats 1 and 3) by `hs(d, k, p)`, so they may wander freely in between (the corpus: 72-75% of beat notes are chord
#     tones); `lb(i)` is the bass note folded into the low octave, `l5(i)` the chord tone nearest a fifth above it.
# Names: a module's own names begin with its slot's letter (L lead, U counter, A arp, B bass, V pads, kk kick, hh hat,
# cp clap, pc perc, roll/sweep seams); the helpers below are shared and identical everywhere.

== species
name lens
title the move book: 12-tone modes through the scale lens h(d), city pop made of graphs
tuning 12-tone modes through the lens h(d) = floor((12d + c) / 7)
meter 4/4, eighths and sixteenths
generator fractal sums (the blancmange), digit integers, bits, Fibonacci, Lissajous
harmony yes
form loop arcs
timbre the pluck, graph-instrument pads, the 808 bass, dash drums
bpm 92 106
weight 2
open bass+hat | pads+perc | lead | kick+bass | arp+counter | pads+lead | bass+clap | counter+hat | kick+arp

== helpers
tri(v) = abs(v - floor(v + 0.5))
sq(v) = floor(2 frac(v))
T(u) = tri(u) + 0.5 tri(2u) + 0.25 tri(4u) + 0.125 tri(8u) + 0.0625 tri(16u)
bit(x, k) = mod(floor(x / 2^mod(k, 16)), 2)
gl(x, y, u, w) = x + (y - x) smooth((u - 1 + w) / w)
Fb(k) = floor(1.618033988749895^k / 2.23606797749979 + 0.5)
lo(p) = mod(p + 4, 12) - 40
lb(i) = lo(Hr(i))
l5(i) = sc(lo(Hr(i)) + 7, i)

# ================================================================================================= bass (lines, not a root on every beat)
# 2026-11-03: basslines should be fluid and more complex, never the root on every beat. So each bass is a line: syncopated bit rhythms with rests and pushes, ghosts, octave jumps, approach notes into
# each chord change, walking chord tones, and slides drawn as curves. Strong beats stay on the bar's chord tones.
# `Bg` re-strikes a legato line: it dips to 0 only at the end of a step whose NEXT step is set in the pattern.
# Register: `lb(i)` folds the half bar's bass note into one low octave (F1 to E2) and `l5(i)` is the chord tone nearest
# a fifth above it, so a line keeps its shape while the progression moves, and never climbs out of the bass. A bass
# plays the bass note the progression wrote, so a written inversion (I/3, V/3) is heard where it was meant.
