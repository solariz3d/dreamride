# SPECIES: LOOPS. Incommensurable loops in 19-tone equal temperament (src/compose/book.rs).
#
# Eno's trick from Music for Airports: each voice is a figure on its own loop, 5, 7, 11, 13, 17, 19, 23 or 29 beats
# long, so the loops drift against each other and rarely realign (5, 7, 11 and 13 together only every 5005 beats). The
# loops run on the stream's clock w = t + 32 S (S is the stage counter), so they carry on across every seam instead of
# restarting. There is no bar and no meter: the music is the phase between the loops. The tuning is 19-tone equal
# temperament, e19(k) = Ek + 12k/19 (its thirds are purer than 12-tone's), through a diatonic mode of 19 Gm(d) whose
# steps are stored two digits each. Timbres are sines and soft bells, long attacks, a lot of air. Sources: B. Eno,
# Music for Airports (1978) and his 1996 talk on generative music; on 19-TET, J. Yasser (1932) and W. Sethares.

== species
name loops
title incommensurable loops in 19-tone equal temperament: no bar, only phase
tuning 19-tone equal temperament, e19(k) = Ek + 12k/19, through a 19-tone diatonic mode
meter none: loops of 5, 7, 11, 13, 17, 19, 23 and 29 beats on the stream's own clock
generator incommensurable loops (polymeter), realigning only at their least common multiple
form a single evolving texture: layers drift in and out, nothing returns on the bar
timbre sines and soft bells
bpm 60 72
weight 1
explore yes
open pads | counter+perc | bass+arp | lead | pads+counter

== helpers
lp(L, a, b) = (frac(w / L) >= a / L)(frac(w / L) < b / L)
el(L) = floor(w / L)

== frame
S = 0
w = t + 32 S
e19(k) = Ek + 12 k / 19
Gm(d) = 19 floor(d / 7) + mod(floor(Gn / 100^mod(d, 7)), 100)

== loops/lead.eleven | lead | energy 2 | density 2 | mood calm wander
# a loop of 11 beats: three notes, each a beat, then silence; every time round the figure starts a degree higher, for five times round
Eh(c, m) = Gm(7 + mod(c + m, 5) + m)
Ea = e19(Eh(el(11), min(floor(11 frac(w / 11)), 2)))

voice lead {
  wave = additive
  partials = 0, -18, -26, -34
  rolloff = 660
  pitch = Ea
  gate = lp(11, 0, 3.2) (0.85 - frac(w))
  gain = 0.2
  pan = 0.15
  attack = 60
  decay = 900
  sustain = 0.4
  release = 900
  reverb = 0.6
  delay = 0.3
}

== loops/lead.voice | lead | energy 1 | density 1 | mood voice longing | glide
# a voice on a loop of 23 beats: a long tone that sighs down a step and then another, sliding, its vibrato arriving late
Ea = e19(Gm(10) + (Gm(9) - Gm(10)) smooth((frac(w / 23) - 0.16) / 0.04) + (Gm(8) - Gm(9)) smooth((frac(w / 23) - 0.28) / 0.04))

voice lead {
  wave = additive
  partials = 0, -16, -24, -32
  rolloff = 660
  pitch = Ea + vibrato(note_age, 0.8, 1.2, 0.2, 5)
  gate = lp(23, 0, 9)
  gain = 0.2
  pan = 0.05
  attack = 600
  decay = 2000
  sustain = 0.6
  release = 1500
  reverb = 0.6
  delay = 0.25
}

== loops/seam.swell | seam | energy 1 | density 1 | mood into-strip into-intro into-return into-peak
# the root and fifth swelling in over the last four beats, as the cube of the time
sweep = e19(Gm(4))

voice rise {
  wave = additive
  partials = 0, -12, -20
  rolloff = 660
  pitch = sweep
  gate = t >= 28
  amp = ((clamp(t, 28, 32) - 28) / 4)^3
  gain = 0.12
  attack = 50
  release = 600
  reverb = 0.6
}
