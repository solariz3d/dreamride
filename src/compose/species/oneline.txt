# SPECIES: ONELINE. The single-curve illusion: one function, one dot, heard as bass, chords and melody (src/compose/book.rs).
#
# One voice draws everything tonal. Its pitch leaps between registers 21 times a second (8 steps a beat at 150-170
# bpm): the bass two octaves down, a chord tone, the melody on top, another chord tone. Faster than about ten notes a
# second and further apart than an octave, the ear stops hearing one line and splits it into streams (Bregman's
# auditory streaming), so a single curve is heard as a band. That is the chiptune arpeggio chord, and the old trick
# of Baroque solo writing (implied polyphony). The melody inside is the ruler sequence, the 2-adic order of the step
# number (0 1 0 2 0 1 0 3 ...), so it has the self-similar rise and fall of a Tower of Hanoi, climbing the chord's
# ladder Hc. Since 2026-11-03 the chords are a written progression (harmony.txt) in the song's key: the curve's bass is
# the progression's bass note, its chord tones the pads' voice-led voicing, its melody the ladder. The breakdown can
# reveal the trick: the melody alone. Sources: A. S. Bregman, Auditory Scene Analysis (1990); L. P. A. S. van Noorden
# (1975) on the temporal coherence boundary; on implied polyphony, J. S. Bach's solo suites and partitas.

== species
name oneline
title the single-curve illusion: one function leaping fast enough to be heard as bass, chords and melody
tuning 12-tone equal temperament: a written progression in the song's key, every step of the curve a chord tone
meter 4/4, eight steps a beat
generator one curve cycling registers (auditory streaming), its melody the ruler sequence
harmony yes
form loop arcs, with the illusion taken apart in the breakdowns
timbre chip squares (odd partials) and dash percussion
bpm 150 170
weight 1
open lead | lead+kick | kick+hat | lead+hat | counter+perc

== helpers
ru(m) = (mod(m, 2) == 0) + (mod(m, 4) == 0) + (mod(m, 8) == 0) + (mod(m, 16) == 0)

# ================================================================================================= progressions
# The progression slot holds the written progressions of harmony.txt (src/compose/harmony.rs adds them as modules).

# ================================================================================================= the curve

== oneline/lead.four | lead | energy 2 | density 2 | mood bright driving
# one curve, four registers: the bass note two octaves down, a chord tone, the ruler-sequence melody on top climbing the chord's ladder, another chord tone, eight steps a beat
Zv(k) = if(mod(k, 4) == 0, Hr(floor(k / 16)) - 24, if(mod(k, 4) == 2, Hc(7 - ru(floor(k / 4)), floor(k / 16)) + 12, Hv(1 + (mod(k, 4) == 3), floor(k / 16))))
Zl = Zv(floor(8t))

voice lead {
  wave = additive
  partials = 0, -120, -9.5, -120, -14, -120, -17, -120, -19
  rolloff = 660
  pitch = Zl
  gate = frac(t / 16) < 0.985
  gain = 0.16
  pan = 0
  attack = 3
  decay = 400
  sustain = 0.8
  release = 60
  reverb = 0.25
  delay = 0.15
}

== oneline/lead.three | lead | energy 3 | density 3 | mood driving

== oneline/lead.revealed | lead | energy 1 | density 1 | mood voice calm | glide
# the trick taken apart: only the melody the curve was carrying, on eighths, gliding into each over the last 40%
Zm(m) = Hc(7 - ru(m), floor(m / 4))
Zl = Zm(floor(2t)) + (Zm(floor(2t) + 1) - Zm(floor(2t))) smooth((frac(2t) - 0.6) / 0.4)

voice lead {
  wave = additive
  partials = 0, -16, -4.5, -15, -11, -18.4, -16.1, -22.9
  rolloff = 660
  pitch = Zl
  gate = frac(t / 8) < 0.96
  gain = 0.18
  pan = 0.05
  attack = 30
  decay = 500
  sustain = 0.7
  release = 250
  reverb = 0.4
  delay = 0.25
}

== oneline/counter.echo | counter | energy 2 | density 2 | mood bright strange
# the second channel's old trick: the four-register curve again, three steps late and an octave up, quiet, panned away
Ze(k) = if(mod(k, 4) == 0, Hr(floor(k / 16)) - 24, if(mod(k, 4) == 2, Hc(7 - ru(floor(k / 4)), floor(k / 16)) + 12, Hv(1 + (mod(k, 4) == 3), floor(k / 16)))) + 12
Zc = Ze(max(floor(8t) - 3, 0))

voice counter {
  wave = additive
  partials = 0, -120, -12, -120, -18
  rolloff = 660
  pitch = Zc
  gate = frac(t / 16) < 0.985
  gain = 0.07
  pan = -0.5
  attack = 3

  sustain = 0.8

}

== oneline/counter.bassline | counter | energy 3 | density 2 | mood driving groove

== oneline/seam.sweep | seam | energy 3 | density 3 | mood into-return into-peak into-intro
# the arpeggio pulled up and out: the last two beats' chord tones climbing four octaves at 16 steps a beat
sweep = Hc(floor(16 (clamp(t, 30, 31.99) - 30) / 3.2), 15)

voice rise {
  wave = additive
  partials = 0, -120, -9.5, -120, -14
  rolloff = 660
  pitch = sweep
  gate = t >= 30
  gain = 0.1
  attack = 2
  release = 80
  reverb = 0.3
}
