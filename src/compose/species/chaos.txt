# SPECIES: CHAOS. The logistic map near the edge of chaos, in 7/8, over written harmony (src/compose/book.rs).
#
# The generator is May's logistic map, x_{n+1} = r x_n (1 - x_n), written as it is: F(x) = r x * (1 - x), and the orbit
# X(n) = iter(F, 0.3, n), the map applied n times. Each lead sets r, the regime: a period-4 cycle (3.5, the cobweb),
# intermittency just below the period-3 window (3.8282, the orbit: long period-3 stretches broken by bursts), and full
# chaos (3.7, the burst); without a lead, the Feigenbaum point where period doubling runs out (3.5699). The arpeggio
# draws the bifurcation diagram itself, r sweeping 2.9 to 3.9 each bar, on the chord's tones; the counter-line is the
# butterfly, the same map from 0.3001, peeling away from the lead. Since 2026-11-03 the harmony is a written
# progression (harmony.txt) in the song's key: the orbit's notes land on the pentatonic of its mode, pn(d) (major or
# minor pentatonic through the lens h), and on the 7/8's accents (eighths 0, 2 and 4 of the bar) on a tone of the chord,
# ac(x, k, n); the basses and pads play the progression. The meter is 7/8 (2+2+3): seven eighths in each four-beat
# bar, an eighth floor(7t/4). Sources: R. May, "Simple
# mathematical models with very complicated dynamics", Nature 261 (1976); Feigenbaum (1978); Pomeau and Manneville
# (1980) on intermittency.

== species
name chaos
title the logistic map at the edge of chaos, in 7/8 on a pentatonic lens
tuning 12-tone equal temperament: a written progression in the song's key, the melody on the pentatonic of its mode
meter 7/8, grouped 2+2+3 (seven eighths in each four-beat bar)
generator the logistic map x(n+1) = r x(n) (1 - x(n)), iterated
harmony yes
form loop arcs
timbre plucks and glass
bpm 110 128
weight 1.2
open bass+kick | lead | arp | pads+perc | hat+counter | bass+hat

== helpers
F(x) = r x * (1 - x)
X(n) = iter(F, 0.3, n)
ob(x, k) = mod(floor(x / 2^k), 2)
Gi = 3 floor(t / 4) + (mod(floor(1.75t), 7) >= 2) + (mod(floor(1.75t), 7) >= 4)
ac(x, k, n) = if((frac(7 mod(k, n) / n) == 0)(mod(7 mod(k, n) / n, 2) == 0)(7 mod(k, n) / n <= 4), sc(x, 2 floor(k / n) + (7 mod(k, n) / n >= 3.5)), x)
lw(p) = mod(p + 4, 12) - 40

== frame
r = 3.5699
pn(d) = h(7 floor(d / 5) + mod(floor(if(c < 4, 64320, 54210) / 10^mod(d, 5)), 10))
