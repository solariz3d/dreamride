#
# T(u) sums 5 tents at halving sizes, each 0.6 the height of the last (the Takagi-Landsberg curve), so every stretch
# looks like the whole. The chord roots are T across the whole song, one sample a bar, times 8. The melody adds T at 3
# time scales (32, 16, 2 lead steps), so each short figure has the shape of the longer ones. The lens h is the Aeolian
# mode throughout. The lead is h(M) on every eighth, plucked, sounding on a Euclidean E(4, 8), gliding into the next
# note. A harmony doubles the lead a diatonic third above. 4 pads stack thirds on the root, struck each bar. A contour
# voice draws the generator across the whole song, held on scale tones by the glide lens g. The bass jumps octaves on
# the root in eighths. The kick is on every beat. The clap is a pitch line dashing down on 2 and 4. The hats are
# eighths, their loudness read from the generator. Form: build, break, return: the drums and bass drop out for section
# 3.

tri(v) = abs(v - floor(v + 0.5))
T(u) = tri(u) + 0.6 tri(2u) + 0.36 tri(4u) + 0.216 tri(8u) + 0.1296 tri(16u)
h(d) = floor((12d + 2) / 7)
g(u) = h(floor(u)) + (h(floor(u) + 1) - h(floor(u))) smooth((frac(u) - 0.7) / 0.3)
R(i) = floor(8 T(i / 16))
M(k) = R(floor(k / 8)) + floor(5 T(k / 32) + 5 T(k / 16) + 4 T(k / 2))
lead(k) = h(M(k)) - 12
lay(N) = mod(floor(N / 10^(3 - s)), 10)
on(k) = mod(4 mod(k, 8), 8) < 4
n = floor(4t)
e = floor(2t)
u = frac(2t)
b = frac(t)
j = floor(t / 4)
s = floor(t / 16)
