# sq(v) is a square wave, 0 for the first half of each cycle and 1 for the second: sums of them at time scales an
# octave apart are binary counting, read as music (Walsh functions). The chord roots are two square waves 4 and 8 bars
# long. The melody is the root plus 4 square waves: 1 x period 4, -2 x period 16, 1 x period 64, 3 x period 32. The
# lens h is the Ionian mode throughout. The lead is h(M) on every eighth, held legato and gliding into each step. A
# harmony doubles the lead a diatonic fifth above. 3 pads stack thirds on the root, struck each bar. An arpeggio walks
# the chord's tones by the generator, every sixteenth. The bass walks the chord's root, third and fifth by the
# generator, one a beat. The kick is drawn from the generator's own sequence. The clap is a pitch line dashing down on
# 2 and 4. The hats are eighths, their loudness read from the generator. Form: the hand songs' shape: all in, the lead
# from bar 5.

sq(v) = floor(2 frac(v))
h(d) = floor((12d + 5) / 7)
R(i) = -2 sq(i / 4) + 3 sq(i / 8)
M(k) = R(floor(k / 8)) + 1 sq(k / 4 + 0.25) - 2 sq(k / 16 + 0.5) + 1 sq(k / 64 + 0.5) + 3 sq(k / 32)
lead(k) = h(M(k)) + 1
lay(N) = mod(floor(N / 10^(3 - s)), 10)
W(x) = sq(x / 4) + sq(x / 2)
n = floor(4t)
f = frac(4t)
e = floor(2t)
u = frac(2t)
b = frac(t)
j = floor(t / 4)
s = floor(t / 16)
