# The Tower of Hanoi's move sequence: at move k the disc that moves is the ruler v(k), and every pitched voice and the kick read it.
#
# v(k) counts the trailing zero bits of k: 0 1 0 2 0 1 0 3 0 1 0 2 0 1 0 4. The little disc moves every other step, the
# bigger ones ever more rarely, the biggest once. The chord root falls by the ruler of the bar (one, two, three scale
# steps, four at bar 16) and returns home every other bar. The lead climbs the ruler of the eighth on top of the
# chord's fifth, so each bar starts high and falls back to the fifth; its highest note (the big disc, v = 6) lands on
# beat 32, the first beat of the Ionian section, on a major chord. The disc voice glides, unquantized, from one
# two-beat move's disc to the next; the glide lens holds each scale step and slides in the last quarter of it. The
# kick lands where a big disc moves (sixteenths 0, 8 and 14 of each bar: every half bar, and an eighth before the
# next); hat accents are the ruler of the sixteenth, capped at 3. From beat 16 a counter-line in quarters reads the
# ruler upside down, below A4: it dips on beat 3 of every bar by the size of the disc that moves there, deepest
# in bars 8 and 16. Pads stack the lens's thirds on the root, with two quiet copies an octave up. Modes from the digits
# of 3254, sixteen beats each: Dorian, Aeolian (darker), Ionian (the bright half, the peak), Mixolydian. Feeling:
# patience, falling home. 10 definitions (plus the time names e, n, f, k2). Clap: a pitch line dashing down on 2 and 4.
# Measured (tools/measure/analyze.py): band energy 35/37/27/1.0/0.2 %, 95 spectral peaks per frame; beats 24-64
# (all voices in) 35/37/26/1.0/0.2 % with 98 (the references: 41/37/20/1.6/0.2 % with 108, and 60/26/13/0.9/0.3 % with 143).

bpm 96

v(k) = (mod(k, 2) == 0) + (mod(k, 4) == 0) + (mod(k, 8) == 0) + (mod(k, 16) == 0) + (mod(k, 32) == 0) + (mod(k, 64) == 0) + (mod(k, 128) == 0)
C = mod(floor(3254 / 10^(3 - min(floor(t / 16), 3))), 10)
h(d) = floor((12d + C) / 7)
g(u) = h(floor(u)) + (h(floor(u) + 1) - h(floor(u))) smooth((frac(u) - 0.75) / 0.25)
R(b) = 0 - v(b + 1)
e = floor(2t)
n = floor(4t)
f = frac(4t)
lead(k) = h(R(floor(k / 8)) + v(k) + 4)
k2 = floor(t / 2)
u = R(floor(t / 4)) + v(k2 + 1) + (v(k2 + 2) - v(k2 + 1)) frac(t / 2)
bassd = R(floor(t / 4)) + 4 (mod(floor(t), 4) == 2)
chord(i) = h(R(floor(t / 4)) + 2i) - 12
big(k, r) = v(k) >= r
