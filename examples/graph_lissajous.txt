# A Lissajous figure X = sin(p th), Y = cos(q th) whose ratio p:q climbs 2:1, 3:2, 4:3, 5:4, one figure per four bars, and the same ratio is the harmony.
#
# th = tau t / 16 turns once per section, so each section's figure closes exactly. The counter glides along Y; the lead plucks the
# sum X + Y on eighths, so its range swells and shrinks where the two curves reinforce and cancel (interference). The
# drone sounds the ratio itself as a just interval, 12 log2(p/q) semitones, computed from the ratio by the log series
# ln r = 2(z + z^3/3 + z^5/5 + z^7/7), z = (p - q)/(p + q): an octave, a just fifth, fourth, major third. The rhythm is
# the ratio too: hats p to a beat (eighths, triplets, sixteenths, quintuplets), claps q to a bar (beat 3, the backbeat,
# triplet halves, the offbeats). The mode brightens as the ratio narrows: c = 3 + s walks the lens h from Dorian through
# Mixolydian and Ionian to Lydian, so the just third of 5:4 meets a major third. 11 definitions.
# Measured (tools/measure/analyze.py): band energy 42/40/18/0.8/0.3 %, 106 spectral peaks per frame (the references:
# 41/37/20/1.6/0.2 % with 108, and 60/26/13/0.9/0.3 % with 143).

s = floor(t / 16)
p = s + 2
q = s + 1
X(x) = sin(p tau x / 16)
Y(x) = cos(q tau x / 16)
c = 3 + s
h(d) = floor((12d + c) / 7)
g(u) = h(floor(u)) + (h(floor(u) + 1) - h(floor(u))) smooth((frac(u) - 0.7) / 0.3)
z = 1 / (2s + 3)
ji = 34.6241 (z + z^3/3 + z^5/5 + z^7/7)
e = floor(2t) / 2
